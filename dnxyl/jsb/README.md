# 大闹西游路（网页版）

用 **Vite + React 19 + TypeScript + Matter.js** 重做的竖屏小游戏，素材来自大闹西游路 Unity 版，不再依赖 Unity。

技术栈对齐 `sbmlapp`：相对路径 `base: './'`，开发端口 **5173**。账号与存档参考 `AIkp`：关闭公开注册，仅管理员可创建用户，进度保存在服务器。

## 运行

需要两个进程（账号服务 + 网页）：

```powershell
cd D:\code\AICODES\dnxyl\jsb
npm install
npm run server
```

另开终端：

```powershell
cd D:\code\AICODES\dnxyl\jsb
npm run dev
```

浏览器打开 **http://127.0.0.1:5173/**

默认管理员（与 AIkp 相同）：`kjxgl` / `kjx.123`。普通账号由管理员在大厅「账号管理」中添加。

存档文件：`server/data/users.json`、`server/data/progress.json`。

## 操作

- 按住屏幕左右拖、或 `A` / `D` / 方向键：横向走位
- 自动向前跑；第 2 关起自动攻击
- 五行各满 20（或修为达标）后点 **突破**，也可用空格 / 回车
- 底部 **暂停 / 继续**（`P` / `Esc`）

突破后会把**当前关卡与生命值**写入服务器。下次登录从上次突破的关卡继续，并带上主角生命。

素材按关卡加载：第一次进入只加载当前关和下一关；每突破一关再加载再下一关，不会一次性载入全部。
