# AI卡牌 · 完善后的玩法流程

## 1. 角色与资产

- **玩家**：本地档案（昵称、排位分、荣耀分、连胜、勋章）。
- **小世界**：题材（历史国度 / 四大名著 / 著名剧集 / 热门小说 / 自定义）+ 出处 + 短背景（即战场）+ 详细背景。玩家不可另设战场。
- **卡牌**：必须属于某个小世界；名称、人物设定、1~3 技能；技能不得超出该世界设定。
- **官方世界**：西游记、三国演义、水浒传、聊斋志异。每人设有阵营、绰号、短设定与技能；可原样选用或修改后审核入库。

## 2. 创建 / 进入小世界

1. 玩家填写世界名、题材、出处、背景、允许的技能题材。
2. 硬校验字数与禁词。
3. 审核 AI 清洗世界背景（将作为战场）。
4. 其他玩家进入该世界后，只能按世界设定铸造卡牌。
5. 官方世界可搜索/按阵营筛选人物：**原样选用**跳过审核直接入库；**修改后入库**走铸造审核。

## 3. 铸造卡牌（必须在世界内）

1. 选择小世界后：空白填写人物与技能，或从官方人物改设定。
2. 本地校验：字数、技能数、禁词、历史世界禁止现代武器等越界词。
3. 审核 AI 对照世界背景与题材约束，越界则不通过。
4. 评级 AI 给出初创评级。

## 4. 排位对决（一对一 / 三对三）

双方必须进入**同一个小世界**。战场固定为该世界背景，不再拼接两套自设战场。

### 4A 联机排位

1. 选择世界、模式、身份、本世界卡组 → `POST /v1/match/queue`（携带 `world`）。
2. 匹配服只配对同一 `worldId`。
3. 服务端用世界背景演算一次战报，双方拉取同一结果。

### 4B 练习战

对手为内置演示卡，战场仍为所选小世界背景。

## 5. AI 双阶段职责

| 阶段 | 职责 |
|------|------|
| 审核 AI | 去限制、校验是否属于当前小世界 |
| 对战 AI | 在世界背景中叙事并裁决胜负 |

## 6. 勋章

初创者、创世、入世、破阵、联阵、连胜、辉光、集结、荣耀百/三百。
