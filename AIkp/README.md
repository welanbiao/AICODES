# AI卡牌（AIkp）

Android AI 驱动卡牌对战：**玩家创建小世界，他人进入铸卡，技能不得超出世界设定；世界背景即战场。**

调试期通过本地 **Cursor SDK 桥** 调用 Cursor 大模型；桥不可用时自动降级本地规则引擎。

## 核心玩法

```text
进入官方小世界（西游记 · 三国演义 · 水浒传 · 聊斋志异）或自创世界
  → 阅读详细背景；点选人物「原样选用」或「修改后入库」
  → 世界背景经审核后锁定为唯一战场
  → 空白铸造的技能/人物不得越出该世界
  → 同世界排位（1v1 / 3v3）
  → 对战 AI 按世界背景生成战报与胜负
```

已取消玩家自设战场。联机匹配只配对进入同一小世界的玩家。

## 规则摘要

| 对象 | 限制 |
|------|------|
| 小世界背景 | ≤80 字，即战场 |
| 卡牌技能 | 最多 3 个；每技能描述 ≤20 字；必须符合该世界题材 |
| 通用禁词 | 无敌、无限、秒杀、影响/控制 AI 等 |
| 历史/名著/剧集 | 额外禁止机甲、枪械等现代越界词 |

**卡牌评级**：初创 · 对战 · 排位荣耀 → 综合档（N/R/SR/SSR/UR）  
**勋章**：初创者、创世、入世、破阵、联阵、连胜、辉光等

## 工程结构

- `app/` — Kotlin + Jetpack Compose Android 客户端（大厅底栏：大厅 / 世界 / 对战 / 卡册 / 我的）
- `ai-bridge/` — Node 本地桥 + 同世界匹配服
- `web/` — Vite 预览（含 AI 生图背景与按钮）

## 官方小世界

大厅 → **世界** 提供四个官方世界（题材化短设定，非原文摘录）。点选人物可原样入库，也可改名、改设定、改技能后再提交审核。

| 世界 | 战场（短背景） | 人物 |
|------|----------------|------|
| 西游记 | 西天取经路，八十一难精怪拦道 | 师徒、仙佛、主要精怪 |
| 三国演义 | 汉末群雄逐鹿，魏蜀吴三分天下 | 蜀汉 / 曹魏 / 东吴 / 群雄 |
| 水浒传 | 水泊梁山聚义，替天行道较武 | 一百零八将 + 晁盖 |
| 聊斋志异 | 花妖狐魅入世，书生侠客夜遇奇缘 | 著名篇目人物 |

也可自创世界（历史 / 名著 / 剧集 / 小说 / 自定义）。

## 调试：接上 Cursor 大模型 + 联机匹配

```bash
cd ai-bridge
npm install
set CURSOR_API_KEY=你的Key
npm start
```

健康检查：`http://127.0.0.1:8787/health`  
Android 模拟器默认 `http://10.0.2.2:8787`。

### 联机接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/v1/auth/register` | 注册（账号+密码+昵称）→ token；用户写入 `ai-bridge/data/users.json` |
| POST | `/v1/auth/login` | 登录 → token |
| POST | `/v1/auth/logout` | 退出（Bearer token） |
| GET | `/v1/auth/me` | 当前用户 |
| PUT | `/v1/auth/profile` | 更新昵称等资料 |
| POST | `/v1/match/queue` | 携带卡组 + **小世界** 入队（同 worldId 才配对） |
| GET | `/v1/match/ticket/:id` | 轮询匹配/战报 |
| DELETE | `/v1/match/ticket/:id` | 取消排队 |
| GET | `/v1/match/lobby` | 队列人数 |
| GET | `/v1/match/leaderboard` | 内存天梯 |

Android / Web 启动后需先**注册或登录**；会话 token 本地保存，用户档案落在服务器 JSON 文件。

## 建议试玩路径

1. **大厅** — 点「开战」或先逛小世界  
2. **进入官方世界** — 阅读详细背景，原样选用人物或修改后入库；也可空白铸造  
3. **创建小世界** — 选题材、写背景（即战场）与题材约束  
4. **排位** — 选同一世界的卡组开战  
5. **战报** — 入场/通用特效与回合叙事  
6. **卡册 / 荣耀册** — 查看收藏与勋章
